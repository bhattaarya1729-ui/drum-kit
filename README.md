# 🥁 Drum Kit — Aarya Bhatt

An interactive browser-based drum machine that lets you play drum sounds
using your keyboard or mouse clicks — with a sleek glassmorphism UI.

---

## 🎮 Demo

> Open `index.html` with **Live Server** in VS Code to run locally.

---

## ✨ Features

- 🎹 **Keyboard support** — press A–L to trigger drum sounds instantly
- 🖱️ **Mouse/click support** — click any pad on screen
- 💡 **Visual feedback** — active pad glows gold and scales up on hit
- 🪟 **Glassmorphism UI** — frosted glass card over a full-screen background
- 🎵 **9 real drum samples** — Bass, Snare, Cymbals, Toms and more

## 🚀 How to Run

1. Clone the repository
```bash
   git clone https://github.com/your-username/drum-kit.git
```

2. Open the folder in **VS Code**

3. Install the **Live Server** extension (if not already installed)

4. Right-click `index.html` → **"Open with Live Server"**

5. Start drumming! 🥁

> ⚠️ Must use Live Server — Chrome blocks audio from local `file://` paths.
